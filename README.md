## 🍵 プロジェクト概要

理不尽な怒号、謎の仕様変更、そして夕方17:55に鳴り響く「ちょっと今いい？」という恐怖のSlackメンション——。
人間が「真面目に責任を取る」行為は、極めてタイパとコスパに劣ることが近年の研究で判明しました。

`SHIN-DOGEZA Cloud` は、あなたの胃壁と尊厳を守るため、最新鋭のAIと画像認識技術、そして極限の現実逃避ロジックを結集して誕生した究極のセーフティネットです。

## 🚀 主要機能

### 1. 全自動言い訳（Ex-Cuse）エンジン 🤖
- やらかしレベル（Lv.1 微遅刻 〜 Lv.5 本番DB消去）と相手の役職を選択するだけで、誰一人反論できない「不可抗力の真実」を生成。
- *「太陽フレアに伴う地磁気嵐の影響により、不可逆的なパケットの消滅が観測されました。物理法則の限界です」*

### 2. 画角最適化・AI土下座シミュレーター 📐
- Webカメラでオンライン会議中の「謝罪の角度」をリアルタイム解析。
- 15度（会釈）は「舐めてるのか」警告。画面から完全アウト（床直撃）で**Sランク「プロの詫び」**と判定され、厳かなBGMがフェードインします。

### 3. エクセル迷彩（Boss Screen）機能 🕶️
- ボス特有の接近気配を察知した瞬間、画面を超難解なマクロ入りスプレッドシートへ偽装（エスケープ・レイテンシー：0.2秒以内）。

### 4. 残業偽装：カタカタゴースト 👻
- 定時退社後も安心。深夜23:45に空行差分プルリクエストを自動投下し、Slackステータスを午前2時に「集中スペース」へ偽装。
